# Workflow: Discovery

## When to use
Когда есть идея, проблема или область, но непонятно, что именно строить.

## Steps

1. **Activate `product`** → сформулировать problem statement
   - Кто пользователь, какая проблема, какие альтернативы
   - Output: `discovery/<topic>-problem.md`

2. **Activate `growth`** → проверить позиционирование
   - Есть ли сегмент, готовый платить или активно использовать
   - Какие альтернативы у них сейчас
   - Output: `discovery/<topic>-positioning.md`

3. **Human checkpoint** → решение продолжать или нет
   - Если идея проходит — формулируется гипотеза для проверки
   - Если нет — discovery закрывается с результатом «не делаем»

4. **Activate `product`** → сформулировать гипотезу и MVP-скоуп
   - Минимальный объём для проверки гипотезы
   - Метрики успеха
   - Output: `discovery/<topic>-hypothesis.md`

## Artifacts
- `discovery/<topic>-problem.md`
- `discovery/<topic>-positioning.md`
- `discovery/<topic>-hypothesis.md`

## Exit criteria
- Есть проблема, сегмент, гипотеза, метрика
- Скоуп MVP сформулирован и помещается в разумный срок
- Решение продолжать или нет принято человеком явно
