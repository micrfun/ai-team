Example target project for AI Team bootstrap.

## What this project is

A small browser app used to test install and bootstrap behavior.

## Stack

- JavaScript
- Vite-style local development
- npm scripts for local commands

## Expected AI Team context

An agent should infer that this is a frontend JavaScript project, that runtime commands should be documented but not run unless the user permits them, and that UI changes should be verified by the user locally.
