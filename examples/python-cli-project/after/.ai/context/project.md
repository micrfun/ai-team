# Project Context

## What we're building

A minimal Python CLI project used as an AI Team example target.

## Who it's for

- **Primary segment**: maintainers testing AI Team bootstrap behavior.
- **JTBD**: verify that an agent can infer Python CLI structure from `README.md` and `pyproject.toml`.
- **Trigger**: testing install, update, or bootstrap workflows.

## Goals

- Provide a small Python target for examples and manual smoke checks.

## Non-goals

- This is not a production CLI.

## Constraints

- Runtime commands are documented but not run by agents unless the user permits them.
